# 🏋️ Workout Telegram Bot

> Персональный тренировочный бот в Telegram — ведёт по каждому упражнению, считает отдых в реальном времени и хранит историю прогресса.


---

## ✨ Возможности

- 📋 **Программа на 3 дня** — Грудь/Плечи/Трицепс, Спина/Бицепс, Ноги/Пресс
- 🖼️ **Фото техники** для каждого упражнения
- ⏱️ **Живой таймер отдыха** с анимированным прогресс-баром (обновляется каждые 15 сек)
- ⚖️ **Изменение веса** прямо во время тренировки
- 📈 **История и прогресс** — графики весов по каждому упражнению
- 💡 **Советы по технике** для каждого упражнения
- 🗄️ **SQLite база данных** — все тренировки сохраняются

---

## 📱 Команды

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список команд |
| `/workout` | Начать тренировку |
| `/today` | Программа следующей тренировки |
| `/history` | История последних 7 тренировок |
| `/progress` | Прогресс по весам |
| `/stats` | Общая статистика |
| `/cancel` | Прервать тренировку |

---

## 🔄 Как работает тренировка

```
/workout → выбор дня → упражнение с фото и советом
    ↓
✅ Подход выполнен
    ↓
😮‍💨 Отдых 120 сек
[████░░░░░░░░░░░░] 105 сек   ← живой прогресс-бар
    ↓
⏰ Время! → следующий подход
    ↓
... повторяется для каждого упражнения ...
    ↓
🎉 Тренировка завершена!
```

## 🛠️ Стек

- **[python-telegram-bot 20.x](https://github.com/python-telegram-bot/python-telegram-bot)** — async Telegram Bot API
- **[aiosqlite](https://github.com/omnilib/aiosqlite)** — асинхронная работа с SQLite
- **APScheduler** (через job-queue) — таймеры и фоновые задачи
- **Docker + Docker Compose** — контейнеризация и деплой
- **SQLite** — хранение данных тренировок и прогресса

---

## 🚀 Деплой

### Требования
- Docker и Docker Compose
- Токен бота от [@BotFather](https://t.me/BotFather)

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/konstantin-fomin/workout-bot.git
cd workout-bot

# 2. Создать .env файл
cp .env.example .env
nano .env  # вставить BOT_TOKEN

# 3. Запустить
docker compose up -d --build

# 4. Проверить логи
docker compose logs -f
```

### Обновление

```bash
git pull
docker compose up -d --build
```

## ⚙️ Конфигурация

В файле `exercises.py` можно изменить:
- Упражнения и их порядок
- Рабочие веса и количество подходов/повторений
- Время отдыха между подходами
- Советы по технике

После изменений:
```bash
docker compose up -d --build
```

---

## 📊 База данных

Бот хранит в SQLite:
- Каждую тренировку (дата, день, статус)
- Каждый подход (упражнение, вес, повторения)
- История позволяет отслеживать прогресс по весам в динамике
